개인정보처리방침

시행일: 2026년 10월 31일 · 운영자: MINOVATION(이하 "운영자")

1. 앱의 목적

"minovation" 앱(이하 "앱")은 운영자가 직접 제작한 영상을 운영자 본인의 YouTube 채널에 업로드·예약 공개하기 위한 자동화 도구입니다. 앱은 운영자 본인만 사용하며 일반 사용자를 대상으로 하지 않습니다.

2. 접근하는 Google 사용자 데이터

앱은 Google OAuth 범위 https://www.googleapis.com/auth/youtube.upload만 요청합니다. 이 권한으로 운영자 채널에 영상과 썸네일을 업로드하고 공개 시각을 설정하는 것 외에는 어떤 데이터도 읽거나 수정하지 않습니다.

3. 수집·저장하는 정보

앱은 다른 사람의 개인정보를 수집하지 않습니다. 운영자 계정의 OAuth 리프레시 토큰은 운영자가 관리하는 클라우드 실행 환경의 비공개 설정(시크릿)에만 저장되며, 영상 업로드 외의 목적으로 사용하거나 제3자에게 제공하지 않습니다.

4. 보관 및 삭제

토큰은 운영자가 앱 사용을 중단하면 즉시 삭제합니다. Google 계정의 타사 앱 액세스 관리에서 언제든 앱의 접근 권한을 철회할 수 있습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. YouTube API 사용과 관련해서는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
